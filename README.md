备份任务按用户给的路径写文件，攻击者在目录里放了一个指向系统配置的链接，覆盖写把服务写坏了：写入前必须解析真实路径并确认在受控目录内；中间目录也不得是链接；写入必须使用不跟随链接的方式；已存在目标不得被静默覆盖；符号链接与硬链接都必须检测；批量任务各任务独立。不变量：任何写入都不会落到受控目录之外；同一路径两次判定结果相同。

# linkguard

## 范围

linkguard 为受控根目录下的文件写入提供路径判定和写入结果。调用方给出根目录、目标路径、写入内容与策略；实现返回结构化结果。

## 契约

- 根目录是全部判定的边界，目标路径必须位于根目录内。
- 解析结果覆盖完整路径，不只覆盖最后一级名称。
- 中间目录和最终组件都属于链接检查范围。
- 已存在的目标不会被写入覆盖。
- 符号链接和硬链接都按不安全目标处理。
- 批量任务逐个处理，任一任务的结果不影响其他任务。
- 同一输入连续两次调用应得到同样的判定。
